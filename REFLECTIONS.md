<p>When you save the file, the changes get added to the file’s cloud or the hard drive stored in the computer. After git add, the changes exist within the staging area, which preps the code you want to be committed. After git commit, the code is sent to the commit history for the repository, which displays your coding milestones for other collaborators to see. After git push, the code gets saved to the repository within the file you’re working with, and it will be accessible for you and others to view it. Lastly, after you use git pull, the code is updated to be the most recent version of the file, if and when you made changes to the file. Git pull also allows you to view errors, such as merging or overlapping. When you create a commit, when you push your edits and pull edits, your partner is able to see those changes.</p>
